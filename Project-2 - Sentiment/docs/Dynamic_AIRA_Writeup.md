# Dynamic AIRA – Project Report

## 1. Project Title

**Dynamic AIRA – Multilingual AI Knowledge Assistant**

## 2. Project Objective

The objective of Dynamic AIRA is to extend the chatbot developed during training into a more capable conversational AI assistant.

The internship implementation focuses on adding practical AI capabilities while retaining the original knowledge-assistant concept.

## 3. Internship Requirements Implemented

The project incorporates the following internship tasks:

1. Sentiment analysis
2. Multilingual conversation
3. Multimodal interaction using text and image inputs
4. Conversational context and continuity

## 4. Sentiment Analysis

Dynamic AIRA analyses the sentiment expressed in user messages.

The supported sentiment categories are:

- Positive
- Negative
- Neutral

The sentiment information can be used to make the assistant's interaction more appropriate to the user's expressed tone.

## 5. Multilingual Capability

Dynamic AIRA was extended to support four languages:

- English
- Hindi
- Tamil
- Kannada

The multilingual capability allows users to interact with the assistant in their preferred supported language.

The implementation also supports conversational continuity while interacting across supported languages.

## 6. Multimodal Capability

Dynamic AIRA supports both text and image inputs.

Users can interact through normal text questions and can also upload an image for image-related interaction.

This extends the assistant beyond a text-only knowledge chatbot.

## 7. Knowledge Base

The assistant continues to use a knowledge base as the foundation for knowledge-oriented interaction.

This preserves the core functionality of the training project while allowing additional AI capabilities to be incorporated into the same assistant.

## 8. Conversational Interaction

Dynamic AIRA provides a GUI-based conversational experience.

Users can:

- Ask questions
- Continue a conversation
- Interact in supported languages
- Express different sentiments
- Provide image input

The assistant is designed to provide a more natural and accessible interaction than the original basic chatbot.

## 9. Demonstration

The project includes demonstration images showing the developed Dynamic AIRA interface and its implemented capabilities.

The demonstrations cover knowledge-based interaction, multilingual interaction, conversational responses, and image-based interaction.

## 10. Technologies

The project uses Python and NLP/AI techniques for:

- Knowledge-based question answering
- Sentiment analysis
- Multilingual interaction
- Conversational processing
- Image-based interaction
- GUI-based user interaction

## 11. Project Outcome

Dynamic AIRA demonstrates the progressive development of a training chatbot into a more capable AI assistant.

The final implementation incorporates sentiment analysis, multilingual interaction in English, Hindi, Tamil and Kannada, and multimodal interaction while retaining the original knowledge-assistant functionality.

This demonstrates the Elevance Skills internship objective of building additional features and capabilities on the existing training project.

## 12. Conclusion

Dynamic AIRA combines knowledge assistance with multilingual, sentiment-aware and multimodal interaction in a single conversational assistant.

The project demonstrates practical application of AI and NLP concepts to improve accessibility, conversational interaction and user experience.
