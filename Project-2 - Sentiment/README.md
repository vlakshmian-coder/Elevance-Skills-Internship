# Dynamic AIRA – Multilingual AI Knowledge Assistant

## Project Overview

Dynamic AIRA is a GUI-based AI knowledge assistant developed as an extension of the chatbot developed during training.

The project was progressively enhanced during the Elevance Skills internship to provide a more capable and user-friendly conversational assistant. The final version combines knowledge-based question answering with multilingual interaction, sentiment analysis, conversational context, and multimodal interaction through image input.

## Internship Tasks Implemented

Dynamic AIRA incorporates the following internship requirements:

- Sentiment analysis to identify positive, negative, and neutral user sentiment.
- Multilingual conversations across English, Hindi, Tamil, and Kannada.
- Multimodal interaction supporting both text and image inputs.
- Conversational interaction while maintaining context across exchanges.
- Knowledge-based responses using the project's knowledge base.

## Key Features

### 1. Knowledge-Based Question Answering

Dynamic AIRA retrieves information from its knowledge base and provides conversational responses to user questions.

### 2. Sentiment Analysis

The assistant analyses the sentiment expressed in user messages and supports responses appropriate to the detected emotional tone.

The supported sentiment categories are:

- Positive
- Negative
- Neutral

### 3. Multilingual Support

Dynamic AIRA supports conversations in:

- English
- Hindi
- Tamil
- Kannada

The assistant is designed to maintain conversational continuity while users interact in different supported languages.

### 4. Multimodal Interaction

The assistant supports both text and image inputs. Users can upload an image and interact with the assistant regarding the visual content.

### 5. Conversational Interaction

Dynamic AIRA provides a simple GUI chat experience where users can ask questions and continue the conversation through multiple interactions.
